## General Information
The Witching Path is an arcade-inspired game created on Microsoft MakeCode Arcade. In the game, the player assumes the role of a lost witch navigating through a maze to find her way home while dealing with a looming time limit and battling various enemies along the way.


## Technologies Used
- Microsoft MakeCode Arcade.


## Setup
Play the game by putting the following link into your browser: https://arcade.makecode.com/S43034-57453-47315-52110
